一 在 VS Code 中初始化本地 Git 仓库

1. 打开你的项目文件夹（如 D:\新建文件夹\ai_spaces）。
2. 点击“源代码管理” 图标（分支图案）。
3. 点击 “初始化仓库”。
   → 此时 VS Code 会在项目根目录创建隐藏的 .git 文件夹。

验证配置：

```bash
git config --global --list
```

应能看到 user.name 和 user.email。

---

三 提交本地代码到本地仓库

1. 在 “源代码管理” 面板中，所有未跟踪的文件会显示在 “更改” 区域。
2. 在 Message 输入框中写一句说明，例如 第一次提交。
3. 按 Ctrl + Enter 或点击 Commit 按钮。
   → 文件被提交到本地仓库（此时尚未上传到 GitHub）。

---

四 在 GitHub 上创建一个空仓库

1. 登录 GitHub，点击右上角 + → New repository。
2. 输入仓库名（建议与本地项目文件夹同名，如 ai_spaces）。
3. 不要勾选 “Add a README file”，保持空仓库。
4. 点击 Create repository。
5. 复制仓库的 HTTPS 地址（例如 https://github.com/你的用户名/仓库名.git）。

---

五 关联本地仓库与 GitHub 远程仓库

方法一：使用 VS Code 图形界面（推荐）

· 在 “源代码管理” 面板中，点击 ··· → “远程” → “添加远程”。
· 远程名称：origin
· 远程 URL：粘贴你复制的 GitHub 仓库地址（末尾需有 .git）。
· 按回车确认。

方法二：使用终端

```bash
git remote add origin https://github.com/你的用户名/仓库名.git
```

验证远程仓库：

```bash
git remote -v
```

应显示 origin 对应的 fetch/push 地址。

六 推送代码到 GitHub

图形界面方式

· 在 “源代码管理” 面板中，点击 ··· → “推送”。
· 如果本地分支尚未关联远程分支，会弹出提示 “The branch 'main' has no remote branch. Would you like to publish this branch?”，点击 OK。

终端方式

```bash
git push -u origin main
```

-u 会将本地 main 分支与远程 origin/main 关联，以后只需 git push 即可。

---

七 处理身份验证（首次推送）

首次推送时，Git 会要求授权访问 GitHub 账户：

1. 终端中会弹出选项，选择 “Sign in with your browser”（按 1 回车）。
2. 浏览器自动打开 GitHub 授权页面，点击 Authorize。
3. 接着弹出 Git Credential Manager 授权窗口，点击 Authorize git-ecosystem。
4. 授权成功后，浏览器显示 Authentication Succeeded，可以关闭页面。
5. 回到 VS Code 终端，推送自动完成，显示类似：
   ```
   * [new branch]      main -> main
   Branch 'main' set up to track remote branch 'main' from 'origin'.
   ```
八 验证上传成功

1. 刷新 GitHub 上的仓库页面（https://github.com/你的用户名/仓库名）。
2. 应该能看到你本地的所有文件和文件夹。
九 日常更新代码的流程

以后每次修改代码后，只需：

1. 在 “源代码管理” 面板中查看变更。
2. 在 Message 输入框中写本次修改的说明（如 修复了登录bug）。
3. 按 Ctrl + Enter 提交（本地）。
4. 点击 ··· → “推送” 或 “同步更改”，一键上传到 GitHub。
