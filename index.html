📚 课外培训约课系统

作者：王奕鑫 | 最后更新：2026年4月20日

✨ 功能特点
  • 📖 课程管理：创建、编辑课程，设置价格与时长
  • 📅 预约系统：学生在线选择课程与时间
  • 👩‍🎓 学生管理：管理学生档案与学习进度
  • 📝 作业管理：发布作业、提交与批改
  • 📊 学习报告：自动生成周报/月报，追踪学习效果
🛠️ 技术栈
  • 前端：Vue 3 + Element Plus
  • 后端：Node.js + Express（规划中）
  • 数据库：MySQL / MongoDB（规划中）
  • 版本控制：Git + GitHub
  • 部署：GitHub Pages（静态演示版）
📌 说明

本系统目前为前端演示版本，完整功能需配合后端使用。源码已上传至 GitHub 仓库，欢迎交流学习。

🔗 仓库地址：https://github.com/wangyixin2026/ai_spaces
